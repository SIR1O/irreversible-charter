# IRREVERSIBLE – The Charter of Strategic Survival

**Author:** P.S.  
**First published:** March 2026  
**License:** [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

A charter for an age in which some conflicts cannot be undone.

*IRREVERSIBLE* proposes twelve axioms of strategic survival at the 
intersection of military doctrine, conflict theory, and existential risk. 
It is written for anyone who wishes to think clearly in an age where 
some actions cannot be reversed.
